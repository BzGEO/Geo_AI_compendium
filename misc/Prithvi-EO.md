# Resources related to the NASA / IBM Prithvi-EO models
*Last updated: 17.05.2026*

* The models live on the [*HuggingFace* platform](https://huggingface.co/ibm-nasa-geospatial). In addition to the Prithvi for Weather and Climate (Prithvi-WxC) models, there are **7 individual Prithvi-EO models** (available [here](https://huggingface.co/collections/ibm-nasa-geospatial/prithvi-for-earth-observation)):
  * [Prithvi-EO-1.0-100M](https://huggingface.co/ibm-nasa-geospatial/Prithvi-EO-1.0-100M) ("pretrained 100M parameter model")
  * [Prithvi-EO-2.0-100M-TL](https://huggingface.co/ibm-nasa-geospatial/Prithvi-EO-2.0-100M-TL) ("pretrained 100M parameter model with temporal and location embeddings")
  * [Prithvi-EO-2.0-300M](https://huggingface.co/ibm-nasa-geospatial/Prithvi-EO-2.0-300M) ("pretrained 300M parameter model")
  * [Prithvi-EO-2.0-300M-TL](https://huggingface.co/ibm-nasa-geospatial/Prithvi-EO-2.0-300M-TL) ("pretrained 300M parameter model with temporal and location embeddings")
  * [Prithvi-EO-2.0-600M](https://huggingface.co/ibm-nasa-geospatial/Prithvi-EO-2.0-600M) ("pretrained 600M parameter model")
  * [Prithvi-EO-2.0-600M-TL](https://huggingface.co/ibm-nasa-geospatial/Prithvi-EO-2.0-600M-TL) ("pretrained 600M parameter model with temporal and location embeddings")
  * [Prithvi-EO-2.0-tiny-TL](https://huggingface.co/ibm-nasa-geospatial/Prithvi-EO-2.0-tiny-TL) ("pretrained 5M parameter model with temporal and location embeddings")
